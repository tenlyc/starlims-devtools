# STARLIMS DevTools 1.7.0 Beta 4

这是以 AI Agent 可控性、MCP 执行可靠性和 STARLIMS 开发反馈闭环为重点的测试版更新。

This beta focuses on controllable AI agents, reliable MCP execution, and a tighter STARLIMS development feedback loop.

## 主要改进 / Highlights

- Codex 与通用 Agent 使用统一的紧凑执行时间线，实时展示读取、搜索、命令、MCP 调用和文件变更。
- 文件变更汇总固定显示在输入区上方，可展开查看逐文件增删统计和 Diff；已写回 STARLIMS 的变更不再要求重复手动确认。
- MCP 执行授权改为对话内卡片，并与“每次询问 / 自动批准安全操作 / 完全访问”策略统一关联。
- 支持在输入框粘贴或选择截图，将真实图片内容传给支持视觉的 Agent，用于反馈和纠正 UI 问题。
- Agent 可按需读取问题、输出和 STARLIMS 日志，并可调用集成的 `starlims-lsp` 进行 SSL 语法检查。
- 企业树、搜索结果和已检出项使用一致的 STARLIMS 类型顺序与图标。
- 修复大脚本保存的 HTTP 413 限制，并增加保存后的重新读取校验，避免失败操作被误报为成功。
- STARLIMS 用户日志默认按最新记录优先显示。
- 修复中文输入法组合输入被 Enter 误发送或焦点更新导致切换的问题，并更新发送按钮视觉样式。
- 内置 Codex 固定使用 HTTPS，并隔离未由 DevTools 配置的 ChatGPT Apps/Plugins MCP，避免 WebSocket 五次重试和远程 `ps/mcp` 阻塞任务。

- Codex and generic agents now share a compact activity timeline for reads, searches, commands, MCP calls, and live file changes.
- A persistent change summary above the composer expands into per-file statistics and diffs; changes already written to STARLIMS no longer require a second manual write action.
- MCP approvals appear as in-conversation cards and follow the unified Ask / Approve safe actions / Full access policy.
- Screenshots can be pasted or selected in the composer and are delivered as real image input to vision-capable agents for UI feedback and correction.
- Agents can inspect Problems, Output, and STARLIMS logs on demand and invoke the bundled `starlims-lsp` SSL validator.
- Enterprise, search, and checked-out trees now use consistent STARLIMS type ordering and icons.
- Large-script saves no longer hit the HTTP 413 default limit, and post-write readback verification prevents failed writes from being reported as successful.
- STARLIMS user logs show the newest entries first.
- Chinese IME composition no longer submits on Enter or loses input state during composer updates, and the send action has a sharper visual treatment.
- Embedded Codex uses HTTPS directly and isolates ChatGPT Apps/Plugins MCPs not configured by DevTools, avoiding five WebSocket retries and remote `ps/mcp` stalls.

## 验证状态 / Validation

- 完整 smoke test、TypeScript、Vite、Electron 构建和 ESLint 基线检查均作为发布门禁执行。
- GitHub Actions 为 macOS arm64 和 Windows x64 构建未签名测试包。
- 实际 STARLIMS 写入与执行仍受当前用户权限和应用内授权策略约束。

- The full smoke suite, TypeScript, Vite, Electron build, and ESLint baseline are release gates.
- GitHub Actions builds unsigned macOS arm64 and Windows x64 beta packages.
- Live STARLIMS writes and execution remain governed by the signed-in user's permissions and the in-app approval policy.

## 安装提示 / Installation notes

测试版安装包未使用商业开发者证书签名。Windows 可能显示 SmartScreen 提示；macOS 首次打开可能需要在“隐私与安全性”中手动允许。

Beta installers are unsigned. Windows may show a SmartScreen warning, and macOS may require manual approval in Privacy & Security.
