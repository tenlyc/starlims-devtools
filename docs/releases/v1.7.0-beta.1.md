# STARLIMS DevTools 1.7.0 Beta 1

这是首个公开测试版，重点验证 STARLIMS AI 开发、共享 MCP、编辑器与跨平台打包能力。

This is the first public beta, focused on validating AI-assisted STARLIMS development, the shared MCP runtime, editor workflows, and cross-platform packaging.

## 主要内容 / Highlights

- Codex 与通用 OpenAI-compatible Agent，支持 Agent、Plan、Debug、Multitask、Ask 模式。
- 独立 `starlims-mcp` Server、19 个 DevTools MCP 工具、来源标记、能力发现与应用内写入审批。
- 统一写入门禁、SHA-256 内容版本指纹、远端冲突阻断和写后重新读取验证。
- HTML/XFD Form Resources 按明确语言读取、修改和保存。
- 可更新、校验、切换和失败回退的 MCP Server 与 `starlims-lsp` 上游组件。
- Data Source SQL 智能提示、执行结果表格、跨平台快捷键和可调整的现代化工作台。
- 单一合并 `SCM_API.sdp`，包含固定的 `starlimsvscode` 上游基础能力和 `starlims-mcp` 扩展。
- 独立中英文 README、双语文档索引，以及 MCP 架构和上游同步策略的中英文版本。

- Codex and generic OpenAI-compatible agents with Agent, Plan, Debug, Multitask, and Ask modes.
- Standalone `starlims-mcp` server, 19 DevTools MCP tools, provenance metadata, capability discovery, and in-app write approval.
- Unified write gates, SHA-256 content fingerprints, remote-conflict blocking, and post-write read-back verification.
- Explicit-language read and write support for HTML/XFD Form Resources.
- Updatable, verified, switchable, and rollback-capable MCP Server and `starlims-lsp` components.
- Data Source SQL intelligence, result tables, cross-platform shortcuts, and a resizable modern workbench.
- One merged `SCM_API.sdp` containing the pinned `starlimsvscode` foundation and `starlims-mcp` extensions.
- Separate Chinese and English READMEs, a bilingual documentation index, and localized MCP architecture and upstream synchronization guides.

## 验证状态 / Validation

- 27 组 smoke tests 全部通过，TypeScript/Vite/Electron 构建通过。
- 已在隔离测试环境的专用空白表单完成真实 MCP 签出、保存、回读、版本冲突阻断、Resources 保存、撤销签出与签入验收。
- macOS 与 Windows 安装包由 GitHub Actions 生成。

- All 27 smoke-test groups and the TypeScript/Vite/Electron build passed.
- The live MCP write path was verified on a dedicated blank form, including checkout, save, read-back, stale-version blocking, Resources save, undo, and check-in.
- macOS and Windows packages are built by GitHub Actions.

## 测试版注意事项 / Beta notes

- 测试版安装包未使用商业开发者证书签名。macOS 首次打开可能需要在“系统设置 → 隐私与安全性”中手动允许；Windows 可能显示 SmartScreen 提示。
- 正式版发布前仍需完成 Developer ID 签名/公证和真实 Windows STARLIMS 环境验收。
- 建议先在测试环境导入 Release 附带的 `SCM_API.sdp`，并使用专用测试页面验证写入操作。

- Beta installers are unsigned. macOS may require manual approval in Privacy & Security, and Windows may show a SmartScreen warning.
- Developer ID signing/notarization and acceptance on a real Windows STARLIMS host remain required before stable release.
- Import the bundled `SCM_API.sdp` into a test environment first and validate writes with a dedicated test page.
