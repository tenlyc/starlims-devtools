# STARLIMS DevTools 1.7.0 Beta 2

这是针对 Windows 应用图标的测试版修复更新。

This beta update fixes Windows application branding.

## 修复内容 / Fixes

- Windows EXE 重新启用资源编辑，程序不再使用 Electron 默认图标。
- 主窗口、调试窗口、任务栏、NSIS 安装器和卸载程序统一使用 STARLIMS DevTools 图标。
- `icon.ico` 现在包含 16、24、32、48、64、128 和 256 像素七档资源，适配资源管理器、桌面和任务栏缩放。
- 新增 Windows 图标 smoke test，防止打包配置再次关闭 EXE 图标写入。

- Re-enabled Windows executable resource editing so the packaged application no longer uses Electron's default icon.
- The main window, debug window, taskbar, NSIS installer, and uninstaller now use the STARLIMS DevTools icon consistently.
- `icon.ico` now contains 16, 24, 32, 48, 64, 128, and 256 pixel resources for Explorer, desktop, and taskbar scaling.
- Added a Windows icon smoke test to prevent executable icon embedding from being disabled again.

## 验证状态 / Validation

- 28 组 smoke tests 全部通过。
- TypeScript、Vite 和 Electron 构建通过。
- macOS 与 Windows 安装包由 GitHub Actions 重新构建。

- All 28 smoke-test groups passed.
- TypeScript, Vite, and Electron builds passed.
- macOS and Windows packages are rebuilt by GitHub Actions.

## 安装提示 / Installation notes

Windows 可能缓存旧版快捷方式图标。建议先退出并卸载 Beta 1，删除旧桌面/任务栏快捷方式，再安装 Beta 2 并重新固定任务栏。

Windows may cache the old shortcut icon. Exit and uninstall Beta 1, remove old desktop/taskbar shortcuts, install Beta 2, and pin the application again.

测试版安装包未使用商业开发者证书签名，Windows 可能显示 SmartScreen 提示；macOS 首次打开可能需要在“隐私与安全性”中手动允许。

Beta installers are unsigned. Windows may show a SmartScreen warning, and macOS may require manual approval in Privacy & Security.
