# STARLIMS DevTools 1.7.0 Beta 3

这是以 AI 开发体验、MCP 效率和桌面一致性为重点的测试版更新。

This beta focuses on the AI development loop, MCP efficiency, and desktop consistency.

## 主要改进 / Highlights

- AI 工作期间可追加指导并调整任务方向，无需等待整个任务结束。
- Agent 时间线显示当前阶段、文件修改和逐文件 Diff，便于审查 AI 实际改动。
- STARLIMS MCP 上下文改为按任务和工具能力针对性选择，减少无关工具查询与整批脚本预加载。
- MCP/Reasoning 活动支持紧凑折叠显示，减少对对话正文空间的占用。
- Windows 原生标题栏和菜单主题跟随应用明暗主题切换。
- 已检出树工具栏固定，并改进类型图标、层级和交互细节。
- 更新双语 README、AI/MCP 架构说明和当前上游组件版本。

- Active AI tasks accept steering messages so users can adjust direction before completion.
- Agent timelines expose execution stages, changed files, and per-file diffs for review.
- STARLIMS MCP context is selected by task intent and tool capability, reducing irrelevant tool discovery and bulk script loading.
- MCP and reasoning activity uses compact, collapsible rows to preserve conversation space.
- The native Windows title/menu area follows the application's light or dark theme.
- The checked-out tree keeps its toolbar visible and improves type icons, hierarchy, and interaction details.
- Bilingual README and AI/MCP architecture documentation now reflect the current upstream component versions.

## 暂缓功能 / Deferred feature

HTML Form 的 Preview、Debug 和 Design 编辑器入口在本测试版中暂时隐藏。底层实验代码保留用于后续开发，但在 Runtime 与 FormDesigner 兼容性达到发布要求前不会作为正式功能展示。

The HTML Form Preview, Debug, and Design editor actions are hidden in this beta. Experimental infrastructure remains for future work but is not presented as a released feature until Runtime and FormDesigner compatibility is reliable.

## 安装提示 / Installation notes

测试版安装包未使用商业开发者证书签名。Windows 可能显示 SmartScreen 提示；macOS 首次打开可能需要在“隐私与安全性”中手动允许。

Beta installers are unsigned. Windows may show a SmartScreen warning, and macOS may require manual approval in Privacy & Security.
